# ДЭ 2026 · Разработчик веб и мультимедийных приложений

Подготовка к ГИА базового уровня по КОД 09.02.07-3-2026. Два модуля по 90 минут, 50 баллов. Опубликованный образец — портал «Корочки.есть».

Дизайн, компоненты и сценарии перенесены из локальной версии [2027-dkip-demo](https://github.com/OlgaKraven/2027-dkip-demo) после переработки интерфейса. Обзор, обучение, тренировка, пробный экзамен, примеры и раздел преподавателя работают в одном интерфейсе. В тренировке можно остановить время. В пробном экзамене время идёт непрерывно. Вариант выбирается до запуска таймера.

Учебные маршруты: PHP + MySQL/MariaDB, Python Flask + PostgreSQL и Python Flask + MySQL. В разделе «Примеры» у каждого стека есть ZIP рабочего портала, схема базы, изображения и порядок запуска через интерфейс Windows. Два маршрута Flask используют один серверный код. Все маршруты используют общие формы, вёрстку и сценарий слайдера.

## Локальный запуск

```sh
npm ci
npm run build
npm test
npm run preview
```

Адрес предварительного просмотра — http://127.0.0.1:4206/.

В пробном экзамене доступны официальный образец и 30 авторских вариантов V01–V30. У каждого варианта два связанных модуля по 90 минут, входные данные, изображения и отдельный ZIP. Варианты используют одну экзаменационную модель; различаются темой, курсами, исходными материалами и задачей на удобство панели администратора.

## Преподавателю

[Презентация в PDF](materials/rvmp-2026-presentation.pdf) содержит условия, 28 шагов Windows и проверку результата на Python Flask с MySQL / MariaDB. Заполните ФИО, должность и кафедру или лабораторию на титульном листе и сохраните свою копию PDF.

В разделе «Преподавателю» откройте презентацию и нажмите «Режим показа». Сценарий остаётся в основном окне, а второе окно показывает текущий слайд аудитории.
