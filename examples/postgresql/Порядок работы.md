# Flask и PostgreSQL

1. В Проводнике распакуйте архив в отдельную папку. В учебном окружении Python должны быть установлены Flask и драйвер из requirements.txt. Список передайте преподавателю при подготовке стенда.
2. Откройте pgAdmin. В дереве сервера щёлкните правой кнопкой Databases → Create → Database. Введите имя базы и нажмите Save. Если создание баз запрещено, откройте выданную базу → Schemas, щёлкните Schemas правой кнопкой → Create → Schema. Введите korochki_2026 и нажмите Save.
3. Щёлкните рабочую базу → Query Tool. Нажмите «Открыть файл», выберите schema.sql. Если вы создали отдельную схему, в первой строке редактора перед кодом файла добавьте `SET search_path TO korochki_2026;`. Нажмите «Выполнить». Обновите Schemas → рабочая схема → Tables. Для новой базы рабочая схема обычно называется public. Проверьте, что видны users, applications и reviews.
4. В редакторе откройте config.example.json. Выберите «Сохранить как» → config.local.json. Впишите имя базы, хост, порт, учебного пользователя и пароль. Если использовали отдельную схему, оставьте в dbname имя выданной базы и добавьте внутри database поле `"options": "-c search_path=korochki_2026"`. Поставьте запятую между соседними полями. В поле secret задайте свою длинную случайную строку.
5. В Проводнике щёлкните app.py правой кнопкой → «Изменить в IDLE». В IDLE выберите Run → Run Module. Дождитесь строки Running on http://127.0.0.1:8212.
6. В браузере откройте этот адрес. Должна появиться форма «Вход». При ошибке соединения сверьте параметры базы в config.local.json и наличие таблиц.
7. Зарегистрируйте пользователя. Для учебного администратора создайте отдельную запись admin01 с паролем KorokNET. В pgAdmin щёлкните users правой кнопкой → View/Edit Data → All Rows. В строке admin01 замените login на Admin и role на admin, затем сохраните. Если запись Admin уже есть, используйте её. Выйдите и войдите с логином Admin и паролем KorokNET.
8. Для проверки М1 укажите module равным 1 в config.local.json и повторите Run → Run Module. Для М2 верните 2 и снова запустите модуль.
