# «Корочки.есть» · Python Flask + PostgreSQL

Подготовьте Python 3.12 x64, PostgreSQL и pgAdmin до отключения сети. В Проводнике нажмите «Извлечь всё» и откройте новую папку. В ней должны быть `database-filled.sql`, `config.example.json`, `app.py`, `requirements.txt`, `public` и `wheels`.

## Импорт базы

1. В pgAdmin подключитесь к серверу. Щёлкните правой кнопкой по Databases → Create → Database. Назовите пустую базу `korochki_2026` и сохраните её. Если уже есть база с этим именем, создайте базу с другим именем.
2. Щёлкните правой кнопкой по новой базе → Query Tool. Проверьте имя базы в верхней строке. Нажмите Open File и откройте `database-filled.sql` из архива. Нажмите Execute script (F5). В панели сообщений проверьте, что скрипт завершился успешно.
3. Обновите Schemas → public → Tables. Откройте по очереди `users`, `applications` и `reviews` через View/Edit Data → All Rows.
4. При работе в выданной базе вместо отдельной базы создайте свою схему `korochki_2026` в Schemas. Перед первой строкой открытого SQL добавьте команду `SET search_path TO korochki_2026;` и только после этого выполняйте скрипт.

## Запуск без интернета

1. Сделайте копию `config.example.json` с именем `config.local.json`. Внутри `database` укажите хост, порт, имя базы в `dbname`, учебного пользователя и его пароль. Для отдельной схемы в выданной базе оставьте в `dbname` имя выданной базы и добавьте внутрь `database` поле `"options": "-c search_path=korochki_2026"`. Отделите его запятой. В поле `secret` задайте собственную длинную случайную строку.
2. Откройте PowerShell в распакованной папке. Выполните три команды по порядку. Оставьте терминал открытым.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --no-index --find-links .\wheels -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

3. В браузере откройте <http://127.0.0.1:8212>. Должна появиться форма «Вход». При ошибке подключения сверьте адрес, порт, реквизиты и схему в pgAdmin.

## Проверка обеих ролей

1. В таблице `users` две учебные записи. В `applications` две заявки, в `reviews` один отзыв. Проверьте эти числа до того, как добавите свои записи.
2. Войдите как `student01` с паролем `Training2026`. В «Моих заявках» видны две записи. У завершённой заявки виден сохранённый отзыв. У второй заявки форма отзыва появится после изменения статуса.
3. Нажмите «Выйти». Войдите как `Admin` с паролем `KorokNET`. В панели администратора видны заявки и логин заявителя. Выберите статус в фильтре, затем верните «Все статусы». У незавершённой заявки выберите «Обучение завершено» и сохраните статус.
4. Снова войдите как `student01`. У этой заявки появилось поле отзыва. Введите короткий учебный отзыв, отправьте его и обновите страницу.

Чтобы сравнить модули, остановите сервер в PowerShell через Ctrl+C. В `config.local.json` измените `module` с 2 на 1 и повторите только команду запуска `app.py`. В М1 курс вводится текстом. После проверки верните 2 и снова запустите сервер.
