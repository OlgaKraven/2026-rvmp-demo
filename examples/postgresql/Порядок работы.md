# Flask и PostgreSQL

1. Распакуйте ZIP и откройте preparation.html. Выполните команды установки из папки wheels и запуска Flask для выбранной СУБД.
2. Откройте pgAdmin. В дереве сервера щёлкните правой кнопкой Databases → Create → Database. Введите имя базы и нажмите Save. Если создание баз запрещено, откройте выданную базу → Schemas, щёлкните Schemas правой кнопкой → Create → Schema. Введите korochki_2026 и нажмите Save.
3. Щёлкните рабочую базу → Query Tool. Нажмите «Открыть файл», выберите database-filled.sql. Если вы создали отдельную схему, в первой строке редактора перед кодом файла добавьте `SET search_path TO korochki_2026;`. Нажмите «Выполнить». Обновите Schemas → рабочая схема → Tables. Для новой базы рабочая схема обычно называется public. Проверьте, что видны users, applications и reviews.
4. В редакторе откройте config.example.json. Выберите «Сохранить как» → config.local.json. Впишите имя базы, хост, порт, учебного пользователя и пароль. Если использовали отдельную схему, оставьте в dbname имя выданной базы и добавьте внутри database поле `"options": "-c search_path=korochki_2026"`. Поставьте запятую между соседними полями. В поле secret задайте свою длинную случайную строку.
5. Запустите Flask в PowerShell из виртуального окружения из preparation.html.
6. В браузере откройте этот адрес. Должна появиться форма «Вход». При ошибке соединения сверьте параметры базы в config.local.json и наличие таблиц.
7. Войдите как student01 / Training2026 и Admin / KorokNET. Сверьте список заявок под обеими ролями.
8. Для проверки М1 укажите module равным 1 в config.local.json и повторите запуск Flask в PowerShell. Для М2 верните 2 и снова запустите модуль.
