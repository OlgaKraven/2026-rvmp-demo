# Flask и MySQL

1. В Проводнике распакуйте архив в отдельную папку. В учебном окружении Python должны быть установлены Flask и драйвер из requirements.txt. Список передайте преподавателю при подготовке стенда.
2. Откройте phpMyAdmin, подключённый к серверу MySQL. Откройте «Базы данных». Введите имя базы, выберите utf8mb4 и нажмите «Создать».
3. Откройте новую базу → «Импорт». Выберите schema.sql и нажмите «Импорт». Разверните новую базу в дереве слева. Проверьте, что видны users, applications и reviews.
4. В редакторе откройте config.example.json. Выберите «Сохранить как» → config.local.json. Впишите имя базы, хост, порт, учебного пользователя и пароль. В поле secret задайте свою длинную случайную строку.
5. В Проводнике щёлкните app.py правой кнопкой → «Изменить в IDLE». В IDLE выберите Run → Run Module. Дождитесь строки Running on http://127.0.0.1:8213.
6. В браузере откройте этот адрес. Должна появиться форма «Вход». При ошибке соединения сверьте параметры базы в config.local.json и наличие таблиц.
7. Зарегистрируйте пользователя. Для учебного администратора создайте отдельную запись admin01 с паролем KorokNET. В phpMyAdmin откройте users → «Обзор» → «Изменить». В строке admin01 замените login на Admin и role на admin, затем сохраните. Если запись Admin уже есть, используйте её. Выйдите и войдите с логином Admin и паролем KorokNET.
8. Для проверки М1 укажите module равным 1 в config.local.json и повторите Run → Run Module. Для М2 верните 2 и снова запустите модуль.
