# «Корочки.есть» · Python Flask + MySQL

До отключения сети подготовьте Python 3.12 x64, MySQL или MariaDB и phpMyAdmin. При локальном развёртывании можно использовать XAMPP. Нажмите «Извлечь всё» и откройте распакованную папку.

## Импорт базы

1. В XAMPP Control Panel запустите Apache и MySQL. Запомните их порты. Откройте phpMyAdmin через кнопку Admin или адрес `http://localhost/phpmyadmin`. Если Apache работает на порту, отличном от 80, добавьте к `localhost` двоеточие и номер порта.
2. Откройте «Базы данных». Создайте новую базу `korochki_2026` с сопоставлением `utf8mb4_unicode_ci`. Если такое имя занято, задайте другое.
3. Выберите новую базу в дереве слева. Перейдите «Импорт → Выбрать файл», укажите `database-filled.sql` из распакованной папки и нажмите «Импорт». В сообщениях проверьте успех. Откройте таблицы `users`, `applications` и `reviews`.

## Запуск без интернета

1. Скопируйте `config.example.json` в `config.local.json`. Внутри `database` укажите адрес, порт, имя базы в поле `database`, пользователя и пароль. В поле `secret` задайте собственную длинную случайную строку.
2. Откройте PowerShell рядом с `app.py` и `requirements.txt`. Выполните команды по порядку. Оставьте терминал запущенным.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --no-index --find-links .\wheels -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

3. В браузере откройте <http://127.0.0.1:8213>. Должна появиться форма «Вход». Если портал сообщает об ошибке подключения, сверьте параметры с phpMyAdmin. В настройках указывается порт MySQL, который может отличаться от порта Apache.

## Проверка обеих ролей

1. В таблице `users` две учебные записи. В `applications` две заявки, в `reviews` один отзыв. Проверьте эти числа до того, как добавите свои записи.
2. Войдите как `student01` с паролем `Training2026`. В «Моих заявках» видны две записи. У завершённой заявки виден сохранённый отзыв. У второй заявки форма отзыва появится после изменения статуса.
3. Нажмите «Выйти». Войдите как `Admin` с паролем `KorokNET`. В панели администратора видны заявки и логин заявителя. Выберите статус в фильтре, затем верните «Все статусы». У незавершённой заявки выберите «Обучение завершено» и сохраните статус.
4. Снова войдите как `student01`. У этой заявки появилось поле отзыва. Введите короткий учебный отзыв, отправьте его и обновите страницу.

Чтобы сравнить модули, остановите сервер в PowerShell через Ctrl+C. В `config.local.json` измените `module` с 2 на 1 и повторите только запуск `app.py`. В М1 курс вводится текстом. Для возврата к М2 верните 2 и снова запустите Flask.
