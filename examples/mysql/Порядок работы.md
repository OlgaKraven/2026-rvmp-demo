# PHP и MariaDB через XAMPP

1. В XAMPP Control Panel найдите Apache и MySQL. Нажмите Start рядом с каждым. У запущенных служб появится цветная подсветка и номер порта.
2. Нажмите Admin рядом с MySQL. В phpMyAdmin откройте «Базы данных», введите имя своей пустой базы, выберите utf8mb4 и нажмите «Создать».
3. Откройте базу, затем вкладку «Импорт». Выберите schema.sql из распакованного архива. Внизу страницы нажмите «Импорт». Слева проверьте появление users, applications и reviews.
4. В Проводнике скопируйте папку примера в C:\xampp\htdocs\rvmp-php. Откройте config.example.json в редакторе. Выберите «Сохранить как» и сохраните копию как C:\xampp\rvmp-php-config.json. Впишите имя базы, порт, учебного пользователя и пароль. Используйте учётную запись своей базы с правами чтения и записи.
5. В браузере откройте http://localhost:8080/rvmp-php/public/index.html. Если Apache работает на другом порту, замените 8080 своим портом. Если Apache работает на 80, порт можно опустить. Должны появиться «Вход» и «Регистрация».
6. Зарегистрируйте пользователя. Для учебного администратора создайте отдельную запись admin01 с паролем KorokNET. В phpMyAdmin откройте users → «Обзор» → «Изменить». В строке admin01 замените login на Admin и role на admin, затем сохраните. Если запись Admin уже есть, используйте её. Выйдите и войдите с логином Admin и паролем KorokNET.
7. Для проверки М1 сохраните в rvmp-php-config.json значение module равным 1 и обновите страницу. В новой заявке будет текстовое поле курса. Для М2 верните 2 и обновите страницу. Вместо свободного поля появится список.
