# «Корочки.есть» · PHP + MySQL / MariaDB

До отключения сети установите XAMPP. В Проводнике нажмите «Извлечь всё» и откройте новую папку. Для портала используются PHP с расширениями `pdo_mysql` и `mbstring`, входящими в XAMPP.

## Импорт базы

1. В XAMPP Control Panel запустите Apache и MySQL. Запомните их порты. Откройте phpMyAdmin через кнопку Admin или адрес `http://localhost/phpmyadmin`. Если Apache работает на порту, отличном от 80, добавьте к `localhost` двоеточие и номер порта.
2. Откройте «Базы данных». Создайте новую базу `korochki_2026` с сопоставлением `utf8mb4_unicode_ci`. Если такое имя занято, задайте другое.
3. Выберите новую базу в дереве слева. Перейдите «Импорт → Выбрать файл», укажите `database-filled.sql` из распакованной папки и нажмите «Импорт». В сообщениях проверьте успех. Откройте таблицы `users`, `applications` и `reviews`.

## Запуск без интернета

1. Из распакованной папки скопируйте `config.example.json` в `config.local.json`. В `database` укажите адрес, порт MySQL, имя базы, учебного пользователя и его пароль. Номер порта укажите числом.
2. В Проводнике откройте распакованную папку, где видна `public`. В адресной строке введите `powershell` и нажмите Enter. Выполните две строки. Оставьте окно открытым.

```powershell
$env:RVMP_PHP_CONFIG = (Resolve-Path .\config.local.json).Path
& C:\xampp\php\php.exe -c C:\xampp\php\php.ini -S 127.0.0.1:8211 -t public
```

3. Откройте в браузере <http://127.0.0.1:8211>. Если PHP установлен в другой папке, подставьте свой путь к `php.exe` и `php.ini`. При сообщении об ошибке подключения сверьте порт и имя базы в phpMyAdmin.
4. При запуске через Apache положите копию распакованного проекта в `C:\xampp\htdocs\rvmp-php`, а настройки сохраните вне `htdocs` как `C:\xampp\rvmp-php-config.json`. В этом режиме адрес программы — <http://localhost/rvmp-php/public/index.html>. Для нестандартного порта Apache допишите его к адресу.

## Проверка обеих ролей

1. В таблице `users` две учебные записи. В `applications` две заявки, в `reviews` один отзыв. Проверьте эти числа до того, как добавите свои записи.
2. Войдите как `student01` с паролем `Training2026`. В «Моих заявках» видны две записи. У завершённой заявки виден сохранённый отзыв. У второй заявки форма отзыва появится после изменения статуса.
3. Нажмите «Выйти». Войдите как `Admin` с паролем `KorokNET`. В панели администратора видны заявки и логин заявителя. Выберите статус в фильтре, затем верните «Все статусы». У незавершённой заявки выберите «Обучение завершено» и сохраните статус.
4. Снова войдите как `student01`. У этой заявки появилось поле отзыва. Введите короткий учебный отзыв, отправьте его и обновите страницу.

Чтобы сравнить модули, измените `module` в используемом файле настроек с 2 на 1 и обновите страницу. В М1 курс вводится текстом. Для возврата к М2 верните 2.
