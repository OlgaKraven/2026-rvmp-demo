0. Установка и настройка программ

  1. Скачайте VS Code для Windows x64 и Git for Windows. Разрешите запуск Git из командной строки. В новом окне PowerShell выполните git --version.
  2. Если выбрали PHP или Flask с MySQL, скачайте XAMPP для Windows. Включите Apache и MySQL (MariaDB) в XAMPP Control Panel и откройте http://localhost/phpmyadmin. Запишите фактический порт MySQL, обычно 3306.
  3. Если выбрали Flask с PostgreSQL, скачайте PostgreSQL с pgAdmin для Windows. В установщике оставьте PostgreSQL Server и pgAdmin. Запишите пароль postgres и порт, обычно 5432. Проверьте подключение к локальному серверу в pgAdmin.
  4. Для обоих вариантов Flask скачайте Python 3.12 для Windows x64. Включите Python Launcher и pip. Проверьте py -3.12 --version. Пакеты wheels из ZIP подготовлены для этой версии и архитектуры.
  5. Для ER скачайте diagrams.net Desktop (Windows installer) или используйте ERD Tool в pgAdmin либо Designer в phpMyAdmin. Проверьте экспорт в PDF и распакуйте ZIP целиком через «Извлечь всё».

Импорт заполненной базы

Создайте новую пустую базу UTF-8. Для MySQL выберите её в phpMyAdmin → «Импорт» → database-filled.sql из ZIP. Для PostgreSQL выберите базу в pgAdmin → Query Tool → Open File → database-filled.sql → Execute script. Сверьте таблицы: в users две записи, в applications две заявки, в reviews один отзыв.

Для входа используйте Admin / KorokNET и student01 / Training2026. Открывайте ZIP своего стека: PHP и Python используют разные форматы хешей паролей. В настройках module: 2 открывает полную версию с ограничениями модуля 2. Для репетиции первого модуля задайте module: 1 и используйте ту же учебную базу.

Flask без интернета

  1. Скопируйте config.example.json в config.local.json. Укажите хост, порт, имя базы, пользователя и его пароль. В MySQL имя базы указывается в database, в PostgreSQL — в dbname. В поле secret задайте собственную длинную случайную строку.
  2. Откройте PowerShell в распакованной папке рядом с app.py. Установите зависимости из ZIP и запустите сервер:
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --no-index --find-links .\wheels -r requirements.txt
.\.venv\Scripts\python.exe app.py

Откройте http://127.0.0.1:8213 для MySQL или http://127.0.0.1:8212 для PostgreSQL. Войдите под двумя ролями, проверьте список заявок и сохранённый отзыв.

Как скачать пакеты к своему проекту

До отключения сети скопируйте wheels и requirements.txt из подходящего архива или на подключённом ПК выполните py -3.12 -m pip download --only-binary=:all: -r requirements.txt -d wheels. В новом проекте создайте свою .venv и повторите установку с --no-index. В VS Code при наличии расширения Python выберите .venv\Scripts\python.exe через Python: Select Interpreter. Если пакета нет, проверьте, что выбрали комплект нужной СУБД и x64 Python 3.12.

PHP без интернета

В XAMPP нужны расширения pdo_mysql и mbstring. Проверьте их командой & C:\xampp\php\php.exe -m. При необходимости включите их в C:\xampp\php\php.ini и перезапустите Apache. Пример использует стандартные расширения PHP, поэтому Composer не требуется.

Скопируйте config.example.json в config.local.json рядом с public. Укажите порт и реквизиты новой базы. В PowerShell из папки проекта выполните:

$env:RVMP_PHP_CONFIG = (Resolve-Path .\config.local.json).Path
& C:\xampp\php\php.exe -S 127.0.0.1:8211 -t public

Откройте http://127.0.0.1:8211. Если используете Apache из XAMPP, сохраните настройки подключения в C:\xampp\rvmp-php-config.json вне общедоступной папки. Порядок запуска через Apache есть в Порядок работы.md внутри ZIP.

ЧаВО об экзамене

Сколько модулей и что сдавать?

КОД 09.02.07-3-2026 содержит два модуля по 90 минут. Для первого подготовьте ER, SQL и работающий портал. Для второго доработайте этот же портал. Состав файлов и папку сдачи уточните на инструктаже.

Будет ли интернет?

КИМ, с. 23, описывает рабочие места в локальной сети без доступа в интернет. Установите ПО заранее, скачайте библиотеки и повторите запуск без сети.

Можно ли взять готовый ZIP, флешку или свои пакеты?

ZIP предназначен для домашней репетиции. На экзамене используйте разрешённые организаторами программы, файлы, справочники и носители. Узнайте заранее, где будут исходные материалы, пакеты и доступ к базе.

Что делать при техническом сбое?

Сообщите эксперту номер места, действие и точное сообщение об ошибке. Дождитесь указаний по продолжению. Дома проверьте, запущена ли служба СУБД и совпадает ли её порт в настройках приложения.

Как проверить результат перед сдачей?

Проверьте, что пользователь видит свои заявки, администратор может сменить статус, а отзыв доступен по условиям задания. Откройте сохранённые PDF, SQL и папку проекта.
