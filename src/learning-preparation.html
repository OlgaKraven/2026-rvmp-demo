0. Установка и настройка программ

Скачайте установщики и архив библиотек до отключения от интернета. Откройте раздел своего стека и выполните его шаги.

  • PHP + MySQL / MariaDB
  • Python Flask + PostgreSQL
  • Python Flask + MySQL

Редактор и Git для всех трёх стеков

  1. Скачайте VS Code · Windows x64 User Installer и запустите установщик. После установки выберите «Файл → Открыть папку» и «Терминал → Создать терминал».
  2. На странице Git for Windows выберите Standalone Installer → x64 Setup. В установщике разрешите использовать Git в командной строке и сторонних программах. В новом PowerShell выполните git --version.
  3. Откройте карточку «Настройте Git и сделайте начальный коммит». Используйте свои учебные имя и почту. Сделайте первый коммит в папке проекта.

PHP + MySQL / MariaDB

  1. Скачайте проверенный установщик XAMPP 8.2.12 x64. В установщике оставьте Apache, MySQL, PHP и phpMyAdmin. Укажите C:\xampp.
  2. Откройте XAMPP Control Panel и нажмите Start у Apache и MySQL. Запишите значения из Port(s). Для стандартного порта Apache откройте http://localhost/phpmyadmin. Если Apache слушает другой порт, добавьте его после localhost:.
  3. В PowerShell запустите & C:\xampp\php\php.exe -c C:\xampp\php\php.ini -m. Найдите в списке pdo_mysql и mbstring. При необходимости включите эти расширения в C:\xampp\php\php.ini и перезапустите Apache. Composer для проекта не нужен.

Python Flask + PostgreSQL

  1. Скачайте Python 3.12 · Windows installer (64-bit). В установщике сохраните компоненты pip и Python Launcher. Откройте PowerShell, выполните py -3.12 --version.
  2. На странице PostgreSQL для Windows выберите Download the installer, затем PostgreSQL 18 для Windows x86-64. Оставьте PostgreSQL Server и pgAdmin. Задайте пароль роли postgres и запишите выбранный порт (обычно 5432).
  3. В pgAdmin выберите Add New Server. В General задайте имя подключения. В Connection укажите Host name/address 127.0.0.1, свой порт, пользователя и пароль. Нажмите Save и проверьте появление Databases.
  4. Скачайте библиотеки Flask и psycopg для Windows x64 · ZIP. Распакуйте wheels в корень своего проекта. В карточке «Проверьте подключение» создайте requirements.txt и установите пакеты из этого каталога.

Python Flask + MySQL

  1. Скачайте Python 3.12 · Windows installer (64-bit). Оставьте компоненты pip и Python Launcher, выполните в PowerShell py -3.12 --version.
  2. Установите XAMPP 8.2.12 x64. Включите Apache и MySQL в панели XAMPP. Откройте phpMyAdmin с порта Apache и запишите порт MySQL для Flask.
  3. Скачайте библиотеки Flask и MySQL Connector/Python · ZIP. Распакуйте wheels в корень своего проекта. В карточке «Проверьте подключение» создайте requirements.txt и установите пакеты из этого каталога.

Установка библиотек Flask без интернета

Откройте PowerShell из корня проекта. Создайте окружение командой py -3.12 -m venv .venv. Выполните .\.venv\Scripts\python.exe -m pip install --no-index --find-links .\wheels -r requirements.txt. Параметр --no-index отключает поиск на PyPI. Команда .\.venv\Scripts\python.exe -m pip check проверяет, что все нужные пакеты установлены.

Если расширение Python для VS Code уже установлено, в команде Python: Select Interpreter можно указать .venv\Scripts\python.exe. Команды в карточках работают из PowerShell сразу после установки Python.

ЧаВО об экзамене

Сколько модулей и что сдавать?

КОД 09.02.07-3-2026 содержит два модуля по 90 минут. Для первого подготовьте ER, SQL и работающий портал. Для второго доработайте этот же портал. Состав файлов и папку сдачи уточните на инструктаже.

Будет ли интернет?

КИМ, с. 23, описывает рабочие места в локальной сети без доступа в интернет. Установите ПО заранее, скачайте библиотеки и повторите запуск без сети.

Можно ли взять готовый ZIP, флешку или свои пакеты?

ZIP предназначен для домашней репетиции. На экзамене используйте разрешённые организаторами программы, файлы, справочники и носители. Узнайте заранее, где будут исходные материалы, пакеты и доступ к базе.

Что делать при техническом сбое?

Сообщите эксперту номер места, действие и точное сообщение об ошибке. Дождитесь указаний по продолжению. Дома проверьте, запущена ли служба СУБД и совпадает ли её порт в настройках приложения.

Как проверить результат перед сдачей?

Проверьте, что пользователь видит свои заявки, администратор может сменить статус, а отзыв доступен по условиям задания. Откройте сохранённые PDF, SQL и папку проекта.
