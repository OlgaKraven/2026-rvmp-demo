0. Установка и настройка программ

  1. Скачайте VS Code для Windows x64 и Git for Windows. Разрешите запуск Git из командной строки. В новом окне PowerShell выполните git --version.
  2. Если выбрали PHP или Flask с MySQL, скачайте XAMPP для Windows. Включите Apache и MySQL (MariaDB) в XAMPP Control Panel и откройте http://localhost/phpmyadmin. Запишите фактический порт MySQL, обычно 3306.
  3. Если выбрали Flask с PostgreSQL, скачайте PostgreSQL с pgAdmin для Windows. В установщике оставьте PostgreSQL Server и pgAdmin. Запишите пароль postgres и порт, обычно 5432. Проверьте подключение к локальному серверу в pgAdmin.
  4. Для обоих вариантов Flask скачайте Python 3.12 для Windows x64. Включите Python Launcher и pip. Проверьте py -3.12 --version. Пакеты wheels из ZIP подготовлены для этой версии и архитектуры.
  5. Для ER скачайте diagrams.net Desktop (Windows installer) или используйте ERD Tool в pgAdmin либо Designer в phpMyAdmin. Проверьте экспорт в PDF и распакуйте ZIP целиком через «Извлечь всё».

Подготовьте библиотеки Flask

Скачайте пакет библиотек для Python 3.12 x64 для MySQL или для PostgreSQL. Распакуйте в свою папку проекта, сохранив имя wheels. Создайте свой requirements.txt по карточке подключения и выполните команды PowerShell из этой карточки.

Проверьте PHP и MySQL

В XAMPP запустите MySQL и Apache. В C:\xampp\php\php.ini убедитесь, что включены расширения pdo_mysql и mbstring. После изменения настроек перезапустите Apache. На этапе подключения создайте свои файлы по карточке и разместите их в проекте C:\xampp\htdocs\rvmp-php. Файл реквизитов храните в C:\xampp\rvmp-php-config.json.

ЧаВО об экзамене

Сколько модулей и что сдавать?

КОД 09.02.07-3-2026 содержит два модуля по 90 минут. Для первого подготовьте ER, SQL и работающий портал. Для второго доработайте этот же портал. Состав файлов и папку сдачи уточните на инструктаже.

Будет ли интернет?

КИМ, с. 23, описывает рабочие места в локальной сети без доступа в интернет. Установите ПО заранее, скачайте библиотеки и повторите запуск без сети.

Можно ли взять готовый ZIP, флешку или свои пакеты?

ZIP предназначен для домашней репетиции. На экзамене используйте разрешённые организаторами программы, файлы, справочники и носители. Узнайте заранее, где будут исходные материалы, пакеты и доступ к базе.

Что делать при техническом сбое?

Сообщите эксперту номер места, действие и точное сообщение об ошибке. Дождитесь указаний по продолжению. Дома проверьте, запущена ли служба СУБД и совпадает ли её порт в настройках приложения.

Как проверить результат перед сдачей?

Проверьте, что пользователь видит свои заявки, администратор может сменить статус, а отзыв доступен по условиям задания. Откройте сохранённые PDF, SQL и папку проекта.
