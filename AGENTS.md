# Проект подготовки РВМП к ДЭ 2026

- Исходный комплект — КОД 09.02.07-3-2026, квалификация «Разработчик веб и мультимедийных приложений», ГИА базового уровня. Образец и критерии берутся из приложенного КИМ, два модуля по 90 минут и 50 баллов.
- Сохраняй оформление эталона в docs/DESIGN.md и применимые сценарии из docs/Страницы и требования.md. Предметные сведения эталона относятся к его собственному КИМ. Сценарий нового курса — docs/scenario.md.
- Условия и исходные приложения доступны до действий. В инструкциях показывай место, действие, ввод, проверяемый результат и исправление ошибки. Для учебных шагов выбирай интерфейс программ. Используй только подлинные снимки действий по текущему комплекту.
- Тренировка использует паузу и отдельный прогресс. Пробный экзамен по опубликованному образцу использует непрерывное время. Условие и файлы доступны в обоих режимах.
- Данные предметной области, условия, критерии и шаги лежат в content. Сборка: npm run build. Тесты: npm test. Перед публикацией проверяй браузерные сценарии, источники и скачивание файлов.
