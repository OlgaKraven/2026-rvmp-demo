# Сценарий проекта РВМП 2026

Проект перенесён из состояния 2027-dkip-demo на 8 ноября 2026 года, включая локальные изменения дизайна поверх 6427060. Файлы стилей, иконки и маскот перенесены из этой копии. Эталон требований зафиксирован в BrainM на ветке codex/dkip-demo-design-spec, коммит 388d9f1.

## Сценарий

1. На обзоре студент видит предметную область, уровень, время и критерии. В материалах открывает условие нужного модуля, страницы КИМ и его приложения.
2. В обучении выбирает PHP + MySQL/MariaDB, Python Flask + PostgreSQL или Python Flask + MySQL. Проходит подготовку, М1 и М2. У этапа есть условие, шаги, справка и финальная карточка результатов. Положение и отметки хранятся отдельно для каждого маршрута.
3. В М1 выделяет пользователей, заявки и отзывы, проверяет модель в интерактивной схеме. Создаёт таблицы в СУБД. Собирает регистрацию, вход, подачу и просмотр заявок, отзывы и администрирование. Проверяет ограничение доступа на сервере.
4. В М2 продолжает тот же проект. Проверяет интерфейс при 390 × 844 px, добавляет слайдер из четырёх изображений с интервалом 3 секунды, выводит ошибки в формах, фиксирует список курсов и формат даты, ограничивает отзывы по статусу и улучшает панель администратора.
5. В тренировке студент может смотреть подсказки, отмечать задания, останавливать общий и текущий таймеры, продолжать и сбрасывать попытку. В пробном экзамене выбирает опубликованный образец или один из 30 авторских вариантов V01–V30. Каждый комплект содержит два связанных модуля и собственный архив. Отсчёт 180 минут идёт непрерывно. Отметки и таймер сохраняются отдельно по стеку и варианту.
6. В примерах выбирает стек, открывает инструкцию запуска и скачивает рабочий портал. В разделе преподавателя выбирает презентацию из тех же шагов.

## Проверки и границы текущей версии

До подстановки данных пройден сценарий эталона. После подстановки повторно проверены все шесть разделов, вкладки, восстановление шага, PDF, пауза и сброс, непрерывный экзамен, презентация и все 16 переходов тура. Проверены две темы при 390, 843 и 1360 px. Схемы MySQL и PostgreSQL исполнены в отдельных временных базах. Две связи, уникальность логина, допустимые статусы и серверное условие доступа к отзыву проверены на корректных и ошибочных данных.

Сквозные порталы развернуты в Windows 11. PHP проверен с XAMPP/MariaDB, Flask — с PostgreSQL и MySQL. Снимки Edge сделаны с работающих экземпляров и привязаны к наблюдаемому результату. Учебные настройки базы находятся вне раздаваемых файлов; проверочные записи созданы в выделенных базах или схеме.

Прогон в Edge подтвердил М1 и М2 во всех трёх маршрутах: регистрация, ограничения по роли и владельцу, работа со статусом, сохранение прежних заявок при переходе между модулями, проверка календарной даты, отзыв после завершения и мобильный экран. В превью показаны выбор V01–V30 и входные данные до запуска таймера.

В двух маршрутах с phpMyAdmin все 28 шагов сопровождаются снимками Windows. Новые кадры показывают пустую базу, структуру users, внешний ключ, настройку экспорта, создание локального репозитория и сохранённый отзыв на мобильном экране. В трёх локальных учебных репозиториях Visual Studio появились исходные коммиты Add .gitattributes и Add project files. Методичка учитывает пустой список изменений сразу после создания. В браузерном проходе все 28 шагов каждого маршрута доступны по порядку, а ссылки на архивы и учебный код открываются. Для новичка добавлены недельный план, данные второй записи и точная подготовка администратора из условия КИМ.

Для PostgreSQL в Windows проверены создание схемы в выданной базе, импорт в Query Tool, ERD For Schema и Backup в формате Plain с Only schemas. В SQL присутствуют три таблицы, строки данных отсутствуют. Обе связи читаются в окне ERD. В проверенном скачанном PNG линии исчезли, поэтому методичка включает сохранение видимой диаграммы через «Ножницы».

После замены выпадающих списков проверены видимые кнопки выбора стека и файлов, а также переход по номеру страницы КИМ, этапа ER и слайда. Все шесть разделов открываются при 390 и 1360 px. В пробном экзамене таймер расположен над выбором варианта. Браузерный проход подтвердил 28 шагов со снимками в каждом стеке.
